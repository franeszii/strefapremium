# Discord Premium Bot

## Instalacja

1. Wgraj pliki na GitHub albo hosting
2. Otwórz plik `settings.json`
3. Wstaw token bota:
```json
"token": "TWÓJ_TOKEN"
```

## Instalacja paczek
```bash
npm install
```

## Uruchomienie
```bash
node index.js
```
